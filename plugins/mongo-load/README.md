# Нагрузчик MongoDB

DBehave запускает `mongo:8.0` и `dbehave/mongo-load:0.1.0` в отдельной сети на каждый эксперимент.
Нагрузчик использует тот же контракт `/health` и `/metrics`, что и
[PostgreSQL](../postgres-load/README.md). В режиме хранения `volume` воркер выделяет MongoDB отдельный
дисковый том и удаляет его после завершения. Для экспериментов с журналом, сжатием и временными
файлами используйте этот режим.

| Сценарий | Что менять | Что смотреть |
|---|---|---|
| `write-heavy` | Размер пачки, payload и число дополнительных индексов. `journalAcknowledged` переключает ожидание журнала при `w: 1`. `blockCompressor` задаёт сжатие новой коллекции: `none`, `snappy` или `zstd`. | P95 пачки, подтверждённые документы в секунду, CPU и байты данных на документ. |
| `read-heavy` | Веса выборок, индекс категории, размер рабочего набора и кеш WiredTiger (`cacheSizeMB` в МиБ, по умолчанию 256). `allowDiskUse` действует на отчёт с сортировкой. | P95 по операциям, занятый кеш, чтения в кеш и дисковый I/O. |
| `mixed` | Веса чтения, обновления и вставки. `hotspot` направляет 90% выборов ключа в первые 10% исходных документов, остальные выборы равномерны по всему набору. | P95 обновлений и пропускная способность. |
| `array-index` | Индекс `items.sku` и число разных SKU в заказе. Генератор сохраняет одинаковую долю совпадений при изменении длины массива. | P95 поиска, размер индексов и статистика `explain` контрольного запроса. |

Для отчёта, который выходит за 100 МиБ памяти сортировки, задайте `datasetRows=100000`,
`reportRows=100000`, `payloadBytes=2048`, `pointWeight=0`, `rangeWeight=0`, `reportWeight=100`
и начните с одного клиента. С `allowDiskUse=true` контрольный отчёт покажет использование временных
файлов. С `allowDiskUse=false` нагрузчик посчитает ошибки `memory_limit`.

Запуски открываются на [дашборде MongoDB](grafana/mongo-run.json) с UID `dbheave-mongo`.
Для сравнения выберите несколько запусков одного сценария MongoDB в истории.
Панель «Подтверждённые записи в секунду» считает документы, а панель «Пропускная способность»
считает операции, в том числе пачки вставок.

Для интеграционных тестов укажите в `DBEHAVE_TEST_MONGO_URI` адрес отдельного экземпляра MongoDB 8.0
без аутентификации. Тесты создают и удаляют свои БД. Команда из корня репозитория:

```sh
DBEHAVE_TEST_MONGO_URI=mongodb://127.0.0.1:27017 ./gradlew :plugins:mongo:test :plugins:mongo-load:test
```
